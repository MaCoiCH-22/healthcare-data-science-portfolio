Medicare Bad Debt Log Scrubber

I built an analyst-led Python application to turn inconsistent hospital Excel workbooks into standardized bad debt logs ready for review.

From source workbook to audit review

Hospital Excel files can have stacked headers, repeated headings and several plausible dollar columns. The application inspects the workbook, lets the analyst confirm the physical column mapping, and reconciles the selected amounts before review.

  1. Inspect workbook structure
  2. Confirm field mappings
  3. Reconcile claimed amounts
  4. Review the log and audit evidence

What the application produces

The Python application writes a 23-column Excel log and records source and mapping decisions in a run manifest. A separate audit-prep workbook brings together source completeness, reconciliation evidence, and potential duplicate risks for analyst review.

Where the analyst decides

The application checks saved mappings against the current workbook layout and lets an analyst confirm or override a suggestion. The launcher stops before audit preparation when scrubbing is incomplete. This browser walkthrough uses fictional data and illustrates one decision from the private application.
